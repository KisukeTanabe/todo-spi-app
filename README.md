# ToDo管理・SPI学習アプリ

## 概要

Spring Bootで作成したToDo管理・SPI学習アプリです。

## 機能
- ToDo追加
- ToDo削除
- ToDo完了
- 締切日時設定
- SPI問題生成
- 答えと解説表示

## 使用技術
- Java
- Spring Boot
- Thymeleaf
- HTML
- CSS

## 今後追加予定
- ファイル保存機能
- H2 Database
- Spring Data JPA
- MySQL
